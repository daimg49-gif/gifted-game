# 《看見小宇宙》美術素材規格（給 ChatGPT）

程式版本：v2（2026-10-12）｜程式：Claude｜美術：ChatGPT

## 怎麼交圖

1. 圖檔放進 repo 的 `assets/art/` 資料夾，**檔名必須一字不差**（例：`assets/art/island.webp`）。
2. 遊戲會自動偵測：有圖就換上，沒圖就用程式畫的備用圖。所以可以一張一張交，不必一次全部完成。
3. 所有圖片**不放任何文字**（按鈕、標籤、數字都由程式畫）。
4. 色調：午夜藍 #18243B、霧青綠 #73B8A5、燈光金 #F4CF87、米白 #FFF8EB。精緻繪本插畫，有光影、材質、前中後景。
5. 單張建議 300 KB 以下，WebP 優先；透明背景的用 PNG。

## 小光角色設定

提著小燈的圓潤森林生物，霧青綠毛色、米白臉、兩隻小耳朵、左手提一盞金色小燈。表情溫和。**不穿學士服、不戴眼鏡或博士帽等代表聰明的道具。** 四張要同一隻角色、同樣比例，腳底對齊圖片下緣上方約 5%。

## 探索島 island.webp 構圖座標

畫面是 3:4 直式。程式會在下列位置疊上透明按鈕和名稱標籤，所以建築**中心要落在這些位置附近**（誤差 ±3% 可以）：

| 地點 | 建築中心（橫 %, 縱 %） | 窗戶位置（亮燈用） |
|---|---|---|
| 家長觀察樹屋（左上） | 25%, 33% | 26%, 32% |
| 機關修理所（右上） | 73%, 30% | 73%, 31% |
| 奇想工坊（左下） | 27%, 59% | 29%, 61% |
| 線索觀星臺（右下） | 73%, 56% | 74%, 56% |
| 碼頭（正下方） | 50%, 84% | 41%, 83%（燈籠） |

- 每棟建築下方約 5% 高度要留一點空地，程式會放名稱標籤。
- **窗戶畫成暗的**（深藍、無光）。孩子完成一站，程式會在窗戶位置疊上金色光暈。
- 四棟之間用小路連接，碼頭在島的下緣。
- 上方 15% 是星空，可以有一彎月亮。

## 不需要畫（程式負責）

軌道零件、星星車、燈塔、方格、踏石與石頭上的圖形、觀星臺的星星、紀念卡、所有按鈕與文字。這些牽涉方向、高度、數據，用生成圖會對不準。

- 代表「聰明」「資優」的符號（學士帽、獎盃、燈泡頭、大腦）
