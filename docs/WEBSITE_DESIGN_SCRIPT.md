# 《看見小宇宙》網站設計腳本

版本：第一版設計稿｜2026-10-12

用途：交給網站開發者與美術製作者使用的製作規格。本稿規劃網站，不代表已完成開發。學校名稱、當年度簡章、資格、日期、連結與聯絡窗口皆須由學校提供並核對後上線。

## 1. 設計目標與範圍

對象：使用手機、關注學校與孩子學習的家長；學生可與家長共同操作。

核心體驗：看見孩子的思考線索 → 認識資優班的學習方式 → 取得正式鑑定與報名資訊。

首頁對家長說：「有些想法，藏在孩子的日常裡。一起玩幾個小任務，看看平常沒留意的思考風景。」

網站為教育宣傳與親子探索用途。家長情境卡與遊戲均為本網站自編素材，不是標準化評量；不提供資優機率、能力排名、資格判定或通過預測。完成與否都能直接取得簡章與報名資訊。

第一版包含：一張探索島、三條入口、六張家長觀察卡、三個學生小遊戲、一張探索紀念卡、課程介紹與報名資訊。無登入、排行榜、聊天機器人、學生資料庫或自由作答自動評分。維護工作以更新學校資料為主。

## 2. 美術與畫面語言

### 世界設定

夜色中的漂浮島，島上住著蒐集想法的小生物。建築由木頭、黃銅機關、玻璃與植物構成；窗裡透出暖光。完成一個區域，對應建築亮燈，不以其他區域變暗表示失敗。

四處地景：家長觀察樹屋、機關修理所、奇想工坊、線索觀星臺。碼頭是通往真實學校與招生資訊的出口。

### 美術要求

- 採精緻繪本插畫，具光影、材質與前中後景；避免用制式圖示加卡片取代主場景。
- 主色：午夜藍 #18243B、霧青綠 #73B8A5、燈光金 #F4CF87、米白 #FFF8EB。
- 主場景可使用插畫，操作元件與文字獨立製作，圖片不嵌入文字。
- 吉祥物「小光」：提著小燈的圓潤森林生物，表情溫和，不穿學士服、不戴代表聰明的道具。
- 動態：樹葉輕晃、星點閃爍、窗光亮起、角色探頭。每次完成的動畫可跳過；減少動態模式顯示靜態狀態。
- 配樂預設關閉，使用者開啟才播放；任何任務不依賴聲音。
- 中文以清楚的黑體為主，正文手機至少 16px，行高約 1.6；不使用文字陰影。
- 正文放在米白或深色實底面板；文字對比須達可讀標準，不能只用顏色傳達結果。

### 手機構圖

首頁先顯示標題、島的主視覺與主要入口。大地圖可上下探索，但三條路線按鈕在首屏清楚可見，不讓家長猜哪棟建築可按。橫向螢幕保持操作面板與地圖並列或居中，不強制轉向。

所有點擊範圍至少 44 × 44px。拖放任務另提供「點選物件，再點選位置」操作。不能因裝置尺寸、手部操作或閱讀速度影響任務完成。

## 3. 網站流程與共通操作

首頁 → 選擇路線 → 家長卡／學生任務 → 探索紀念卡 → 課程介紹 → 鑑定與報名資訊。

三條入口：

| 入口按鈕 | 路線 | 預估時間 |
| --- | --- | --- |
| 我想觀察孩子 | 六張家長情境卡 → 家長探索卡 | 2–3 分鐘 |
| 讓孩子試試看 | 三個遊戲，可自由選序 → 孩子探索卡 | 4–6 分鐘 |
| 我們一起探索 | 六張家長卡 → 三個遊戲，每關後附親子觀察提示 → 合併探索卡 | 8–10 分鐘 |

時間為設計估計，試玩後調整。首頁與每頁右上角均有「鑑定與報名」，不必完成遊戲才能查看。

共通操作：返回島嶼、上一頁、略過這一站、關閉聲音。離開任務保留當次進度；重新開始前詢問是否清除。沒有倒數計時、生命值、總分或通關門檻。

只在目前分頁暫存進度，不跨裝置同步。第一版不送出家長選項與孩子作答，不要求姓名、生日、學校、電話或照片。自由文字僅留在當次分頁，重新開始會清除。

## 4. 首頁逐幕腳本

### 幕 01：島嶼醒來

畫面：鏡頭略微拉近漂浮島，小光提燈從樹後探頭。動畫最長 2 秒，畫面出現時即可操作。

標題：「看見小宇宙」

副標：「一起發現孩子的思考風景」

引導：「有些想法，藏在孩子的日常裡。從觀察或遊戲開始，看看你會發現什麼。」

三個主要路線按鈕依前表呈現。另有文字連結：「直接了解資優班」與「查看鑑定與報名」。

入口下方小字：「這是親子探索活動，不是資優鑑定；遊戲表現不影響報名資格。」

### 幕 02：選擇後的引導

家長路線小光：「不用替孩子挑最漂亮的答案，回想你真的看過的情況就好。」

孩子路線小光：「這裡可以試、可以改，也可以先跳過。準備好就出發！」

親子路線小光：「孩子負責探索，大人先看一看；卡住時，可以問『你現在想試什麼？』」

按鈕：「出發」。

## 5. 家長觀察樹屋：六張日常卡

畫面：樹屋桌上有六張插畫卡，一次翻開一張。進度呈現「第 1 張／共 6 張」。每張卡用一個具體場景，不使用「超常」「天才」等暗示答案的詞。

共通問題：「回想最近幾個月，你是否看過類似情況？」

共通選項：「常看見」「偶爾看見」「還沒留意」。可返回修改、可略過；沒有正確答案，也不顯示累積分數。

| 卡片 | 插畫場景與卡面文字 | 記錄主題 |
| --- | --- | --- |
| 1. 為什麼後面，還有為什麼 | 孩子盯著水滴，旁邊浮出幾個不同問號。「得到答案後，孩子有時還會繼續追問原因，或提出另一個問題。」 | 提問 |
| 2. 我的研究小角落 | 桌上是恐龍、摺紙或機械材料。「遇到喜歡的事物，孩子會自己找資料、試做，或反覆研究細節。」 | 深入興趣 |
| 3. 等等，這裡怪怪的 | 孩子指著故事或排列中的不一致。「孩子有時會注意到規律、矛盾或別人沒留意的小細節。」 | 留意線索 |
| 4. 我有另一個辦法 | 用椅子與紙板搭出不同橋樑。「遇到問題，孩子會提出與常見做法不同的想法，或改造原有方法。」 | 多元解法 |
| 5. 有些地方快，有些地方慢 | 同一個孩子一邊投入解謎，一邊整理散落用品。「孩子在某些領域理解得快或投入很多，但其他日常事情仍需要提醒與協助。」 | 不同面向的差異 |
| 6. 腦袋裡很多，說出來不容易 | 想法泡泡很多，紙上只有幾個記號。「從聊天或實作看得出孩子有想法，但書寫、作業或口頭表達未必完整呈現。」 | 表達方式 |

### 家長路線結果

標題：「你留意到的日常線索」

按原順序列出選為「常看見」「偶爾看見」的卡片，保留家長的原選項，最多六項。不加權、不排序、不計分。略過與「還沒留意」不被當作缺乏特質。

文案：「這些是你回想起來的生活片段。接下來可以留意：孩子在哪些情境最投入？用了哪些方法？需要什麼協助？」

如果沒有選項：「今天先留下一個觀察任務：找一件孩子願意主動投入的事，聽聽他為什麼喜歡。」

共通提醒：「這些描述不是資格判定；是否符合報名條件，請以當年度正式簡章為準。」

按鈕：「讓孩子玩一站」「看看資優班」「鑑定與報名」。

## 6. 孩子遊戲一：機關修理所

### 情節與題目

小光：「星星快遞的軌道斷了！幫它鋪一條能抵達燈塔的路。」

操作任務：「選一個軌道，放進格子；點軌道可以旋轉。準備好後，按『試跑』。」

### 可實作的關卡規則

3 × 3 方格。星星從左上格的西側進入；目的地在右下格的東側。每格可放一個零件。零件無數量限制，只有兩類：直軌、彎軌。可旋轉、移除、替換；不需要填滿九格。

直軌有東西、南北兩種朝向。彎軌有北東、東南、南西、西北四種朝向。試跑只沿實際連通的端口移動；遇空格、邊界或端口不相接即停在該處。只有從右下格東側抵達燈塔算接通。軌道形成迴圈時停止試跑，避免動畫無限循環。

至少兩條可行路線：沿最上排向右，再沿最右列向下；或沿最左列向下，再沿最下排向右。兩條都從右下格東側離開。

### 回饋與協助

停住：「星星停在這裡了。看看前後軌道的開口，有沒有接上？」停住的格子以外框與箭頭標示，保留配置，可修改重試。

接通：「星星到站了！你把軌道接成了一條路。」燈塔亮起。

按鈕：「再找另一條路」「下一站」。第二條路為選玩，不影響結尾。

「給我一點提示」第一層：「每個軌道都有兩個開口。」第二層：顯示目前斷點。第三層：「看看一條示範路線」，播放上排與右列範例。使用提示不扣分、不貼負面標籤。

親子路線關後提示：「剛才孩子怎麼決定下一步？先想好、邊做邊試，或看過提示再調整，都可以聊聊。」不要求家長填答。

紀念卡只記錄接通、重試、查看提示、完成另一條不同連通路線等實際操作。不同路線以實際走過的格子序列判定；不以點擊次數推論毅力、智力或策略高低。

## 7. 孩子遊戲二：奇想工坊

### 情節與題目

畫面：一隻背著行李的毛球站在河邊，對岸有小屋。

小光：「毛球想過河，可是牠不想碰到水。你會怎麼幫牠？」

桌上有三件可選工具：會伸縮的雨傘、能浮起來的盒子、很長的繩子。孩子可挑一至三件放到工作臺。

接著選使用方式：「做一座橋」「做一艘船」「讓牠從上面移動」「我有別的想法」。任何工具與方案的組合都可提交；工具不與固定正解綁定。

最後出現選填文字：「這個方法怎麼幫牠過河？」最多 80 字；可以只選圖像就完成，也可與家長口述。語音錄製不納入第一版。

### 動畫與回饋

前三種使用方式分別播放橋、船、繩索運送的短示意動畫，並顯示使用者挑選的工具。動畫表示選擇，不能宣稱物理上已證明可行。

選「我有別的想法」時，呈現空白設計板與使用者工具／文字，不強行播放不相符的方案。

完成文案：「這是你的過河提案！接著可以想想：工具要怎麼固定？毛球上去後會不會滑下來？」

按鈕：「換一種提案」「帶著想法出發」。不判定創意高低、不自動評分自由文字。

親子提示：「請孩子說說工具怎麼用，先聽完，再一起討論可以怎麼試。」

紀念卡呈現選擇的工具、方案及選填原文。所有自由文字以純文字顯示，不解析為 HTML。

## 8. 孩子遊戲三：線索觀星臺

### 情節與題目

畫面：兩盆同種類植物 A、B，種下時同高；兩週後 A 明顯較高。

小光：「它們一起種下，為什麼長得不一樣？你想先查什麼？」

四張可自由打開的資料卡，數據均為虛構遊戲素材：

| 線索卡 | 打開後的具體資料 |
| --- | --- |
| 起點紀錄 | 同一天種下、同種類，起始高度均為 5 公分。 |
| 光照紀錄 | A 每天約 6 小時光照；B 每天約 2 小時。 |
| 澆水紀錄 | A、B 每天各澆 50 毫升水。 |
| 土壤與盆子 | 使用同一袋土壤，同尺寸花盆。 |

不在資料卡旁寫「光照是原因」「其他條件已排除」等判斷；交由孩子思考。可以只開一張，也可以全部查看。

接著問：「如果想繼續查，你想先做哪一件事？」

選項與回饋：

- 「讓兩盆接受一樣的光，再繼續記錄。」→「你想觀察調整光照後會發生什麼。這可以當作後續追蹤；想更清楚比較，也可以用新的同齡植物設計測試。」
- 「用新的同齡植物，只改變光照時間來比較。」→「你提出一個比較方法。接著想想：哪些條件需要保持一樣？要記錄什麼？」
- 「多觀察幾天，記下高度與環境。」→「你想蒐集更多紀錄。可以先決定每天什麼時間、用什麼方式測量。」
- 「我有別的問題。」→ 開啟選填 80 字欄位；回饋「把問題留下來，看看需要哪種資料才能回答。」

任何選項都能完成，紀念卡呈現查看過的線索及所選下一步，不給探究能力分數。課程訊息：「資優班的探究活動，可以從一個問題開始，練習找資料、設計比較與說明想法。」

親子提示：「孩子現在的想法是什麼？哪一張資料讓想法改變？也可以保留『還不知道』。」

## 9. 探索紀念卡

畫面：島嶼上的已探索建築亮起，中央浮出米白紀念卡。只完成一站也有完整結尾；沒有探索任何區域時則顯示「下次可以從任一站開始」。

標題：「今天的小宇宙紀錄」

卡片分區：

- 「家長留意到的片段」：家長卡原選項；沒走此路線就不顯示。
- 「孩子今天做了什麼」：如「接通了一條軌道」「提出一個過河方法」「查看了光照與澆水紀錄」；僅顯示實際操作。
- 「下一次可以聊聊」：依完成區域提供一個問題，例如「你最想把哪個想法真的做出來？」

共通結尾：「短短幾個任務，只能看見今天的一小部分。孩子的興趣、經驗與需要，可以在生活裡繼續了解。」

功能：「下載紀念卡」與「繼續探索」。下載在裝置端產生，標示「親子探索紀錄・非鑑定結果」，不得印製資優認證或能力徽章。首頁分享只分享網站網址，不自動分享作答。

下一段大按鈕：「看看真實的資優班」。較小但清楚的按鈕：「直接看鑑定與報名」。

## 10. 資優班介紹：從遊戲走回真實課程

畫面：從幻想島碼頭走向真實課程相簿，使用學校授權公開的照片或學生作品。不以虛構教室、活動或資源代替學校實況。

標題：「這些思考，可以在哪裡繼續長大？」

三張課程卡，各一張圖、約 40–60 字，內容須由老師核對：

1. 提問與探究：「從好奇出發，練習提出問題、蒐集資料與說明發現。」
2. 創作與解題：「嘗試不同方法，把想法做成作品，透過測試再修改。」
3. 合作與自我了解：「與同學交流，也逐漸了解自己的學習方式與需要。」

實例欄位預留［學校實際課程名稱］［一句真實活動描述］［既有成果連結］。未確認的實例不上線。避免承諾保證升學、提高成績、保證獲獎，或將資優班描述成所有孩子都適合的方案。

補充：「課程安排、服務方式與招生對象，請依學校說明及當年度簡章確認。」

按鈕：「了解鑑定與報名」。

## 11. 鑑定與報名頁

這頁可從所有區域直接進入。用清楚資訊卡呈現，取消遊戲裝飾與長動畫，方便家長查找。

標題：「想進一步了解？從正式資訊開始。」

導語：「無論今天玩了幾站，都可以了解報名條件與流程。親子探索活動不決定是否能報名。」

| 可更新欄位 | 呈現規則 |
| --- | --- |
| ［學校名稱／鑑定年度］ | 年度清楚標示，不能只寫「今年」。 |
| ［報名資格］ | 引用並核對官方規定；不根據遊戲結果篩選訪客。 |
| ［報名開始與截止日期］ | 包含日期、必要時含截止時間。 |
| ［辦理方式與所需資料］ | 簡潔整理，完整規範連結官方簡章。 |
| ［官方簡章連結］ | 按鈕「閱讀正式簡章」，旁註 PDF 或外部頁面。 |
| ［官方報名連結］ | 按鈕「前往報名／查看報名方式」，依實際流程命名。 |
| ［校方正式諮詢窗口］ | 顯示單位、電話或官方信箱；不放老師私人 LINE。 |
| ［資料更新日期］ | 清楚顯示，方便確認時效。 |

未提供正式資料時，開發預覽顯示「正式資料待學校確認」，報名按鈕停用。公開版必須完成資料核對；不可使用猜測日期、舊年度連結或假報名表。

報名開始前顯示「報名尚未開始」；截止後顯示「本年度報名已截止」，仍保留簡章與窗口。狀態使用臺灣時間，不能將舊簡章自動改年度。資格、鑑定方式與重要提醒以官方簡章為準。

## 13. 開發分期與驗收

### 第一階段：美術與操作樣版

完成首頁、探索島、角色、修理所一個可操作關卡，以及完整頁面流程。先檢查手機的氛圍、文字可讀性與手指操作，再擴充內容。

### 第二階段：完整體驗

加入六張家長卡、工坊與觀星臺、三路線共用進度、紀念卡、課程與報名頁。避免為不同路線複製三套遊戲，降低維護成本。

### 第三階段：正式資料與試用

由學校確認招生資訊與課程圖片；找少量家長、孩子試玩，觀察是否能找到簡章、理解操作、完成關卡，以及是否誤以為結果代表資優資格。依問題修正，不以滿意稱讚代替可用性檢查。

### 上線前驗收

- 三條路線、只玩一站、全部略過、返回修改、重新開始均有正常出口。
- 所有頁面可直接到報名資訊，結果不限制資格與連結。
- 修理所兩條範例路線都可接通，斷點與迴圈可安全停止，旋轉後端口判定正確。
- 自由文字不接受 HTML，不送出；提示與重試不影響任何能力判定。
- iPhone Safari 與 Android Chrome 的實機／相應測試環境檢查觸控、旋轉、下載卡片與外部連結。不能只靠桌面模擬宣稱實機通過。
- 大字模式、鍵盤操作、螢幕閱讀標籤、減少動態均可用；拖放有點選替代。
- 所有正式連結、年度、資格、時間與窗口均經核對；公開畫面無待填欄位。
- 低速載入時先顯示文字與入口，插畫延後載入，失敗仍能看簡章。

## 14. 維護與成效判斷

將學校名稱、簡章、日期、資格、窗口、課程圖片集中為單一設定，年度更新不改遊戲程式。由行政提供並確認正式資訊，資優班老師核對課程內容即可，避免新增固定發文與持續出題工作。

第一版不收集作答與個人資料。若未來需要了解招生效益，可在正式詢問或報名流程由學校統一詢問「從哪裡得知資訊」，區分班導師推薦、學校公告、家長分享及互動網站；這是後續評估建議，不是本版新增表單。網站點擊與遊戲完成本身不能證明增加報名，也不能直接證明教學成效。

網站可供班導師透過既有班級管道轉發。轉發建議文字：「想了解孩子的思考方式，也認識資優班？這裡有幾個親子探索小遊戲，並附正式鑑定與報名資訊。活動不是鑑定，也不需要先證明孩子很厲害才能查看資訊。」

開發時使用獨立的新專案與新 GitHub repository，避免覆蓋既有遊戲。正式開發前確認專案位置；本設計稿不修改任何既有網站。
